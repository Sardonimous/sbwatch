DejaVuSans.ttf is DejaVu Sans reduced to the characters SBWatch uses (Basic Latin,
Latin-1 / Extended-A/B, Cyrillic, common punctuation, and the Arabic blocks including
the Presentation Forms). Layout tables and hinting were removed because the Roku does
not use them. The original font and license: https://dejavu-fonts.github.io/
